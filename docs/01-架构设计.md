# 架构设计

基于 **Spring Boot 3 + Vue 3** 的全栈外卖平台，前后端分离，支持**用户端、商家端、骑手端、管理端**四大角色，集成支付宝沙箱支付、WebSocket 实时推送、Redis 缓存与分布式锁。

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        浏览器（Vue3 SPA）                      │
│  用户端  │  商家端  │  骑手端  │  管理端                        │
└──────────────┬──────────────────────┬────────────────────────┘
               │ HTTP(/api)           │ WebSocket(/ws)
               ▼                      ▼
┌─────────────────────────────────────────────────────────────┐
│                        Nginx（反向代理）                       │
│  静态资源托管 · /api 反代 · /ws 升级 · gzip 压缩               │
└──────┬───────────────┬─────────────────┬─────────────────────┘
       │  /api         │  /uploads       │  /ws
       ▼              ▼                ▼
┌─────────────────────────────────────────────────────────────┐
│                Spring Boot 后端（8080）                        │
│  Controller → Service → MyBatis-Plus Mapper                   │
│  JWT 认证 · AuthInterceptor · WebSocket · @Async 通知          │
└───┬──────────────────────┬──────────────────┬────────────────┘
    ▼                      ▼                  ▼
┌─────────┐        ┌────────────┐      ┌──────────────┐
│  MySQL  │        │   Redis    │      │   支付宝 SDK   │
│  8.0    │        │ 缓存/锁/限流 │      │  （沙箱）      │
└─────────┘        └────────────┘      └──────────────┘
```

- 前端与后端**完全分离**，分别构建为独立镜像，由 Nginx 统一对外提供服务。
- 对外仅暴露 **8091 端口**（前端入口）；后端 8081 与 MySQL/Redis 均不直接暴露，仅通过容器内网通信。

## 2. 后端架构

### 分层设计

采用经典分层架构，依赖方向自上而下：

```
Controller（REST 接口）
      ↓
Service / ServiceImpl（业务逻辑，面向接口编程）
      ↓
Mapper（MyBatis-Plus / 自定义 SQL）
      ↓
Entity + MySQL
```

| 分层 | 职责 | 目录 |
|------|------|------|
| Controller | 参数接收、鉴权、返回统一 Result | `controller/` |
| Service | 核心业务，接口在 `service/`，实现在 `service/impl/` | `service/` |
| Mapper | 数据访问，MyBatis-Plus | `mapper/` |
| Entity | 数据库实体映射 | `entity/` |
| DTO | 请求/响应传输对象 | `dto/` |
| Config | 各类配置类 | `config/` |
| Interceptor | 认证/权限拦截 | `interceptor/` |
| WebSocket | 实时推送处理器 | `websocket/` |
| Common | 统一返回 Result、常量 | `common/` |
| Task | 定时任务（订单超时、配送超时等） | `task/` |
| Util | 工具类 | `util/` |

### 核心机制

- **统一响应**：所有接口返回 `Result { code, message, data }`，前端 Axios 拦截器自动解包。
- **统一异常**：`GlobalExceptionHandler` 集中处理业务异常、参数校验异常、兜底异常。
- **统一前缀**：`ApiPrefixConfig` 为所有 API 统一添加 `/api` 前缀。
- **认证授权**：`AuthInterceptor` 校验 JWT（含用户 ID、手机号、角色），按角色进行接口级权限控制。

## 3. 前端架构

Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios。

```
src/
├── api/        # 按业务域封装的 Axios 接口模块（store/order/rider/admin...）
├── components/ # 公共组件（Layout、NavBar、ErrorBoundary...）
├── composables/# 组合式函数（useRiderWebSocket 骑手实时推送）
├── router/     # Vue Router（hash 模式，按 meta.auth/merchant/admin 控制权限）
├── stores/     # Pinia（user 用户态 / cart 购物车 / notification 通知）
├── views/      # 页面组件（按 user/merchant/rider/admin 分目录）
└── utils/      # 工具函数
```

- 路由采用 `createWebHashHistory`（hash 模式），无需服务端路由配置。
- 路由守卫与后端 `AuthInterceptor` 规则一致，实现前后端双层权限控制。
- Axios 拦截器负责携带 Token、处理 401 跳转登录。

## 4. 四大角色设计

| 角色 | 说明 | 对应前端目录 |
|------|------|-------------|
| 用户 end_user | 注册登录、浏览、购物车、下单支付、订单、评价 | `views/` |
| 商家 merchant | 店铺、菜品、分类、订单处理、评价回复、收益 | `views/merchant/` |
| 骑手 rider | 注册审核、在线、抢单、配送、收益 | `views/rider/` |
| 管理 admin | 用户、店铺、骑手审核、系统管理 | `views/admin/` |

## 6. 关键设计亮点

1. **接口化 Service 层**：业务全部面向接口编程（`XxxService` → `ServiceImpl`），`@Transactional`/`@Async` 置于实现类，保证 Spring AOP 代理生效。
2. **订单状态机**：待支付 → 已支付 → 制作中 → 配送中 → 已完成，配以 `order_status_log` 全链路审计日志。
3. **骑手抢单并发安全**：Redis 分布式锁防止重复抢单，WebSocket 实时推送新订单。
4. **通知可靠性**：通知先持久化到数据库，再通过 WebSocket 实时推送；推送失败仅记录日志，不影响主流程。
5. **前后端权限双控**：后端拦截器 + 前端路由守卫基于角色同步控制。
6. **离线可部署**：镜像导出压缩包 + docker load，支持内网/离线服务器部署。
